# Wallpapers

A personal collection of high-quality wallpapers organized by category with standardized clean filenames and a JSON metadata index.

## Categories

- **[anime/](anime)**: 24 wallpapers (One Piece, Demon Slayer, Naruto, Fantasy Art, etc.)
- **[movies/](movies)**: 4 wallpapers (DC & Marvel heroes)
- **[others/](others)**: 52 wallpapers (Cityscapes, Vehicles, Space, Mobile Art, Landscapes, Wallhaven collection)

## Naming Convention

All image filenames follow a clean `kebab-case` format without resolution tags or download hash clutter (e.g., `luffy-sun-god-nika.jpg`, `batman-dc-hero.jpg`).

## Metadata Index

Complete metadata is available in [wallpapers.json](wallpapers.json), including width, height, aspect ratio, file size, format, and category for every wallpaper in the repository.

## Usage

Feel free to browse through the directories or parse `wallpapers.json` to integrate with custom scripts, desktop wallpaper swappers, or web galleries.
